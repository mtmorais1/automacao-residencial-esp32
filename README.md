🏠 Automação Residencial Inteligente com ESP32

1. Apresentação

Este projeto tem como objetivo desenvolver um sistema de automação residencial inteligente utilizando o microcontrolador ESP32, permitindo controlar dispositivos e monitorar informações de um ambiente residencial.

O sistema utilizará sensores, comunicação MQTT, Node-RED e banco de dados SQLite para oferecer controle e monitoramento em tempo real.

2. Objetivo geral

Desenvolver um protótipo de automação residencial capaz de controlar a iluminação, detectar presença e monitorar as condições do ambiente.

3. Funcionalidades previstas

* Controle de iluminação pelo celular ou computador.
* Acionamento automático da iluminação por presença.
* Monitoramento de temperatura e umidade.
* Monitoramento da luminosidade do ambiente.
* Controle manual por botão físico.
* Armazenamento de dados em banco SQLite.
* Visualização das informações em um dashboard.

4. Componentes previstos

* ESP32.
* Módulo relé.
* Lâmpada LED.
* Sensor de presença PIR.
* Sensor de temperatura e umidade DHT22.
* Sensor de luminosidade LDR.
* Botões físicos.
* LEDs indicadores.
* Resistores.
* Protoboard e jumpers.
* Fonte de alimentação adequada.

5. Tecnologias utilizadas

* Arduino IDE: programação do ESP32.
* Wokwi: simulação do circuito eletrônico.
* MQTT: comunicação entre dispositivos.
* Node-RED: processamento dos dados e automação.
* SQLite: armazenamento das informações.
* GitHub: documentação e armazenamento dos arquivos do projeto.

6. Critérios de avaliação

O projeto será desenvolvido para atender aos seguintes critérios:

1. Dispositivos de entrada e saída: sensores, botões, relé e iluminação.
2. Periférico dedicado ou interrupção: utilização de ADC, PWM, timers ou interrupções.
3. Comunicação MQTT: integração do ESP32 com Node-RED.
4. Banco de dados SQL: utilização do SQLite através do Node-RED.
5. Simulação: desenvolvimento e testes no Wokwi.
6. Protótipo físico: montagem e funcionamento em bancada.
7. Dashboard: interface de monitoramento e controle no Node-RED.
8. GitHub: documentação e organização dos arquivos.
9. Vídeo: apresentação demonstrando o funcionamento do projeto.

7. Desenvolvimento

O desenvolvimento será realizado em etapas:

* Planejamento do circuito eletrônico.
* Simulação no Wokwi.
* Programação do ESP32.
* Configuração da comunicação MQTT.
* Desenvolvimento dos fluxos no Node-RED.
* Integração com o banco SQLite.
* Criação do dashboard.
* Montagem e testes na bancada.
* Documentação e apresentação final.

8. Situação do projeto

Projeto em desenvolvimento.

Os códigos, diagramas, imagens da montagem, arquivos de simulação e resultados dos testes serão adicionados a este repositório conforme o desenvolvimento avançar.
